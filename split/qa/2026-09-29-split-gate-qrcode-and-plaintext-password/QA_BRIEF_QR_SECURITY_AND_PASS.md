## 🎯 驗收背景與本次修復核心

1. **【P0 安全漏洞】老師投影畫面 QR Code 旁路直通修復**：
   - **網址列即時脫敏 (URL Sanitization)**：講師直通通過驗證的瞬間，系統立即呼叫 `window.history.replaceState` 自動抹除網址列中的 `role`、`r`、`adm`、`admin` 參數，網址列僅保留純淨的 `?c=班級代碼`。即使隨意用瀏覽器對畫面產碼，也絕不洩漏免密權限。
   - **大螢幕專用「📱 學生報到 QR」投影彈窗**：在講師頂部列（TopBar）新增專屬按鈕，提供白底高對比的學員專用 QR Code 彈窗，該 QR Code 嚴格以白名單只包含 `?c=班級代碼`，並同場展示超大字體之班級代碼與進班密碼，方便全場學員看清。
   - **中央後台班級卡片同步支援 QR Code 彈窗**：`admin.html` 班級列表同步支援直接彈出專用學員 QR Code。

2. **【P2 體驗優化】學員登入密碼輸入取消遮蔽**：
   - 將密碼欄位改為 `type="text"`，採用等寬字體並標記「（明文顯示，方便確認打字）」，取消自動更正與拼字檢查，讓學員清楚看到自己輸入的內容。

## 📋 5 大核心驗收場景與驗收標準 (Acceptance Criteria)

### 🧪 TC-01：講師進班網址列即時脫敏
- **操作步驟**：以帶有 `?c=qa-split-test-01&role=instructor&adm=agile-2026` 網址進入講義。
- **驗收標準**：
  1. 成功進入講師身分（擁有講師工具列與專屬權限）。
  2. 網址列中的 `role`、`r`、`adm`、`admin` **已被完全抹除**，只剩下 `?c=qa-split-test-01`。

### 🧪 TC-02：大螢幕學生報到 QR Code 彈窗
- **操作步驟**：講師進入後，點擊頂部列「📱 學生報到 QR」按鈕。
- **驗收標準**：
  1. 成功彈出高對比、大尺寸投影專用 QR Code 視窗。
  2. 視窗內顯示超大字體的「班級代碼」與「進班密碼」。
  3. 視窗內顯示的學員專屬網址僅為 `.../workshop/split/?c=qa-split-test-01`，**完全不含任何講師或直通參數**。

### 🧪 TC-03：防直通漏洞攔截測試（核心）
- **操作步驟**：
  1. 在講師投影畫面直接複製脫敏後的網址（或以學生角度掃碼）。
  2. 開啟另一個**全新無痕視窗**（模擬學生手機掃碼）造訪該網址。
- **驗收標準**：
  1. 無痕視窗**必須被門禁強制攔截**，出現「SPLIT 需求拆解實戰工作坊」登入畫面。
  2. **絕對不能自動免密登入，亦不能擁有講師身分**。

### 🧪 TC-04：學員密碼明文輸入體驗
- **操作步驟**：在無痕視窗的進班門禁介面上輸入密碼。
- **驗收標準**：
  1. 密碼輸入框呈現為明文字元（`type="text"`，非 `••••••••` 圓點遮蔽）。
  2. 上方有清楚提示「（明文顯示，方便確認打字）」。
  3. 輸入預設密碼 `split-2026` 後能正常驗證並進入學生講義。

### 🧪 TC-05：中央管理後台 QR Code 投影
- **操作步驟**：開啟 `admin.html`，在 SPLIT 班級卡片上點擊「QR Code」按鈕。
- **驗收標準**：
  1. 彈出班級 QR Code 視窗。
  2. 顯示對應之班級代碼與學員專屬網址。
  3. 掃描或複製該網址進入後為標準門禁畫面。
