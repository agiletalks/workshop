## 二、 BUG-0927-07 根因與修復措施

### 1. 缺陷根因分析
在前期修復代碼中，降級容錯文章使用了：
```javascript
`#### 實務敏捷落地與案例\n${part2 || '依課堂講授核心脈絡落實實務敏捷實踐。'}`
```
當講師講授內容僅為單句（如 `今天只驗證付款逾時`）或極短標點片段時，後半部 `part2` 為空字串，邏輯預設回退至該模板語句，導致在降級文章中出現未在語音中出現的無依據字句。

### 2. 修復落實 (Commit `c6d6ed9`)
1. **條件式輸出實務案例段落**：若無 `part2`，完全省略該章節段落，絕不補入任何模板語句。
2. **斷句長度門檻調整**：將斷句門檻由 `length >= 2` 改為 `length >= 1`，確保極短詞句亦能正確納入分詞處理。
3. **修復後代碼**：
```javascript
let articleContent = `### 核心主旨：${slideTitle}\n\n#### 概念深度剖析\n${part1 || safeTranscript}`;
if (part2 && part2.trim().length > 0) {
  articleContent += `\n\n#### 實務敏捷落地與案例\n${part2}`;
}
parsedData = {
  stickies: generatedStickies,
  textbookArticle: articleContent
};
```
