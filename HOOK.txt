# HOOKED｜從自動反應到心理僵化

## 中文版 16:9 RWD HTML 講義逐頁規格

本版本依照英文原教材的頁面順序、學習節奏與心理曲線重新編排。整體共 **15 頁**，保留以下原始設計邏輯：

> 隱喻開場 → 建立學習焦點 → 引發身體與故事反應 → Kiki–Bouba 直覺實驗 → 揭露心智機制 → 定義 Hooked → 嚴肅案例 → 個人／團隊／組織分析 → 回到自身經驗 → 辨識故事與語言 → 形成日常練習

---

# 一、全套講義的核心用語

為兼顧原文概念與中文口語自然度，建議全套固定採用以下用語。

| 英文                   | 中文主要用語     | 課堂口語補充        |
| -------------------- | ---------- | ------------- |
| Hook                 | 勾住我們的東西／鉤子 | 讓我們卡住、被帶著走的東西 |
| Hooked               | 被勾住        | 卡在某個想法、情緒或角色裡 |
| Story                | 腦中的故事      | 我們對事情形成的解讀    |
| Instant storytelling | 瞬間編出的故事    | 大腦立刻認定事情是怎麼回事 |
| Emotional rigidity   | 心理僵化       | 看不見其他可能、轉不過來  |
| Narrowing            | 視野收窄       | 選項愈來愈少        |
| Representation       | 內在表徵       | 我腦中對事情的版本     |
| Reality              | 現實／實際發生的事  | 可以觀察或確認的情況    |
| Step Out             | 拉開距離       | 從故事裡退一步       |

## 全單元核心定義

> **當我們把腦中的故事當成事實，並讓它開始接管行動，我們就被勾住了。**

## Story 的補充定義

> **腦中的故事，是大腦根據有限線索，對事情快速形成的解讀。**

## 核心關係

```text
事情發生
→ 身體與情緒產生反應
→ 大腦迅速形成故事
→ 我們把故事當成事實
→ 被故事勾住
→ 視野收窄
→ 行動選項減少
```

# 二、HTML 整體呈現規格

## 1. 基本形式

* 桌面版以 **16:9 橫式單頁畫面**呈現。
* 每一頁視為一個獨立的 `section`。
* 桌面版每頁建議使用：

  * `min-height: 100vh`
  * `aspect-ratio: 16 / 9`
  * 畫面中央對齊
* 使用者可透過：

  * 向下捲動
  * 上一頁／下一頁按鈕
  * 鍵盤方向鍵
  * 頁面導覽列
    切換內容。

## 2. RWD 原則

### 桌面版：寬度 1024px 以上

* 維持完整 16:9 畫面。
* 可採左右雙欄、上下分區或大色塊構圖。
* 單頁內容原則上不需捲動。
* 活動填答區可直接編輯。

### 平板版：寬度 768–1023px

* 優先保留頁面閱讀順序。
* 雙欄可維持，但欄寬調整為約 40%／60%。
* 字級適度縮小。
* 填答區仍需保有足夠高度。
* 若單頁內容略高，可允許單頁內部少量垂直捲動。

### 手機版：寬度 767px 以下

* 不強制維持 16:9。
* 每頁改為直向內容卡。
* 原本左右雙欄改為上下排列。
* 圖片、標題、文字、填答區依學習順序排列。
* 不以縮小整張投影片的方式處理。
* 最小內文字級建議 16px。
* 按鈕可點擊區域至少 44×44px。

## 3. 填答功能

所有學員填答處建議使用：

* `textarea`
* `input`
* 可點選量表
* 可選擇按鈕
* 可畫線或標記的案例文字

建議支援：

* 自動儲存至 `localStorage`
* 匯出文字紀錄
* 清除單頁內容
* 清除全部內容
* 列印／轉存 PDF

## 4. 頁面共同標示

每頁左下或右下保留 Emotional Agility 四步驟：

1. **如實看見｜Show Up**
2. **拉開距離｜Step Out**
3. **依價值行動｜Walk Your Why**
4. **繼續向前｜Move On**

本單元主要涵蓋前兩步，可使用較深文字或高亮：

* **如實看見**
* **拉開距離**

## 5. 頁面類型識別

| 頁面類型 | 識別文字                     | 建議視覺      |
| ---- | ------------------------ | --------- |
| 章節頁  | 主題                       | 大色塊       |
| 練習   | Exercise／練習              | 紅色或桃紅抽象圖形 |
| 書寫邀請 | Invitation → Journal     | 橘色抽象圖形    |
| 案例研究 | Field Notes → Case Study | 藍色抽象圖形    |
| 強力提問 | Powerful Question        | 大字與大量留白   |
| 反思   | Invitation → Reflection  | 橘色圖形      |
| 證據基礎 | Evidence Base            | 藍灰資訊框     |
| 口袋練習 | Pocket Practice          | 深色小卡      |

# 第 2 頁｜引言：腦中的電影

## 學習階段

**建立隱喻**

## 預期心理狀態

* 共鳴
* 辨認熟悉的內在台詞
* 開始覺得這個主題與自己相關
* 尚未進入防衛

## 頁面目的

* 從電影的 Hook 轉入日常心智運作。
* 說明人會持續在腦中編寫並播放故事。
* 初步呈現被勾住時的典型語言與後果。

## 頁面標題

# 腦中的電影，一直在播放

## 對應原文小標

> 一個故事如何反過來寫下我們

## 正文

一部電影能否吸引觀眾，往往取決於它的「Hook」——一個簡單卻能抓住注意力、啟動情節並推動故事向前的核心設定。

我們的心智也在做類似的事。

每天的每一分鐘，我們都在替發生的事情編寫劇本，而這些劇本會在腦中的電影院裡播放。

但在自己的故事裡，被勾住並不一定令人著迷。它更常表現為一種讓人失去彈性的自動反應：

> 「再試也沒有用。」

> 「我們一直都是這樣做。」

> 「反正沒有人會聽。」

團隊與文化也會被勾住。

部門壁壘、僵硬規則、未受檢視的慣例，以及那些經常出現的「他們就是抗拒改變」，都可能排擠調整與適應的空間。

電影繼續播放，視野逐漸收窄，情節也愈來愈缺乏可能。

你已經看過這部電影。

我們的想法與感受，開始取代實際發生的事。

我們習慣採取的行動，開始取代真正需要的行動。

同一幕不斷重演，一次又一次。

這就是腦中的電影。

這就是被勾住。

## 填答區

無。

## 視覺規格

* 文字集中於畫面中央或右側。
* 三句內在台詞需獨立成段。
* 使用電影底片、反覆播放或線條循環的抽象隱喻。
* 不需使用具體人物照片。

## 講師使用提示

本頁適合由講師慢速朗讀。

在以下句子後稍作停頓：

* 「你已經看過這部電影。」
* 「同一幕不斷重演。」
* 「這就是被勾住。」

# 第 3 頁｜我們將探索什麼？為什麼重要？

## 學習階段

**建立學習地圖**

## 預期心理狀態

* 理解課程範圍
* 知道議題不只與個人情緒有關
* 開始意識到它也會影響團隊與系統

## 頁面目的

* 說明 Hooked 可能來自多種來源。
* 建立個人、關係、團隊與組織的影響範圍。
* 為後續活動提供觀察方向。

## 上半部標題

# 我們將探索什麼？

## 上半部正文

我們都曾經歷過這樣的時刻：

一個想法、感受、角色、群體、故事，甚至某個情境本身，開始接管我們。

「我就是這樣。」

「我們就是這樣。」

我們的選項隨之減少。

在這個單元中，我們將探索：

* 如何察覺自己被勾住的時刻。
* 心理僵化如何出現在我們自己身上。
* 它如何出現在我們支持的人身上。
* 它如何進入團隊、關係與組織系統。
* 如何重新拉開距離，找回選擇。

## 下半部標題

# 為什麼這很重要？

## 下半部文字

* 當感受、想法、角色、故事或情境開始替我們決定行為，我們會與當下經驗黏在一起，視角收窄，選項減少。
* 這種融合會改變關係中的語氣，削弱心理安全感，並促使人防衛或逃避。
* 它會影響決策、合作、身心狀態，以及工作與生活的日常品質。
* 在不確定、時間壓力與複雜情境下，個人和團隊更容易變得僵化，策略與文化也會更加脆弱。

## 核心句

> **心理僵化會縮小我們的視野，也縮小我們的選擇。**

## 填答區

無。

## 視覺規格

* 上半部使用藍灰色區塊。
* 下半部使用橘色大區塊。
* 「為什麼重要」可垂直排在區塊左側，忠實呼應英文版。
* 四項影響使用圓點條列。

2. 探索內容

# 手術室中的 Hook

## 案例正文

2005 年 3 月，Elaine Bromiley 因一項小型手術前往醫院。她長期受到鼻竇問題困擾，醫師準備進行處置，以改善鼻腔內部的情況。

她的丈夫 Martin 向她道別後，帶著兩個孩子離開醫院，進行每週例行採買。

幾個小時後，Martin 接到電話。Elaine 在麻醉期間出現呼吸道問題，而且沒有正常甦醒。她的血氧濃度大幅下降，隨後被轉入加護病房。Martin 抵達醫院時，妻子已陷入昏迷。幾天後，他同意關閉維生設備。

後續調查顯示，手術開始後不久，Elaine 的呼吸道幾乎立刻塌陷。

麻醉醫師依照標準作法，先嘗試使用呼吸器供給氧氣。他呼叫支援，另一位麻醉醫師與一位外科醫師先後到場。

團隊接著嘗試將呼吸管插入 Elaine 的呼吸道，也就是進行插管，但始終沒有成功。

病人在無氧狀態下只能存活大約十分鐘，之後便可能產生不可逆的腦部傷害。

在「無法通氣、無法插管」的危急情況中，基本原則是停止反覆嘗試插管，改以直接方式讓氧氣進入呼吸道。通常的處置是從頸部切開緊急氣道，也就是進行氣管切開或環甲膜切開。

手術室裡的三位醫師合計擁有約六十年的經驗。他們知道相關指引，卻沒有切換做法，而是一次又一次地嘗試插管。

當三位醫師終於將呼吸管插入時，已經超過二十五分鐘，一切都太遲了。

在醫師持續嘗試插管的期間，一位清楚看見狀況的護理人員主動準備了緊急氣道器材，但她的建議沒有被採納。

另一位護理人員前往預訂加護病房床位，後來看到醫師似乎對她的安排反應強烈，便取消了預訂。

醫師沒有退一步重新理解正在發生的事，也沒有從方案 A 切換到方案 B。

事後，手術室內的護理人員表示，她們很驚訝沒有任何一位醫師執行緊急氣道處置，但她們當時不覺得自己可以直接挑戰醫師。

她們預設，在這樣的關鍵時刻，主動領導局面的醫師可能會對護理人員的介入抱持偏見。

## 區塊二｜為什麼這個方法有效？

### 群體極化

**Group Polarization**

當原本已經持有相似觀點的人一起討論時，他們離開討論時通常會更加確定，也更不願意接受其他可能。

### 承諾升高

**Escalation of Commitment**

當人與團隊已經投入時間、地位或資源，即使結果顯示應該停下來，他們仍可能繼續原本的做法。

### 身分融合

**Identity Fusion**

當個人感覺自己與某個群體「合而為一」，群體的故事便容易被感受成自己的故事；與群體故事衝突的資訊也更容易被排除。

# 九、中文講義的核心句統一

整份講義建議反覆出現以下六句，形成學習記憶點：

1. **你現在認定事情是怎麼回事？**
2. **這是事實，還是你對事情的解讀？**
3. **你現在正在相信哪一個故事？**
4. **這個故事讓你看不見什麼？**
5. **有什麼正在發生，卻沒有人說出來？**
6. **還有什麼可能，是我們目前沒有看見的？**

這六句形成完整的微型介入流程：

```text
說出目前的解讀
→ 區分事實與故事
→ 辨識自己被什麼勾住
→ 看見視野收窄的代價
→ 說出未被命名的訊號
→ 重新打開可能性
```

整套教材的最終學習成果，不是要求學員停止編故事，而是協助他們察覺：

> **大腦一定會編故事，但我們不必讓第一個故事成為唯一的真相。**
